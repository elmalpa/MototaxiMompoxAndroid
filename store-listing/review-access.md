# Acceso para revisión de Google Play

La aplicación requiere inicio de sesión.

Antes de enviar a revisión, crear dos cuentas sobre la base de producción:

- Cliente de revisión: `[TELEFONO]` / `[CONTRASEÑA]`
- Conductor de revisión: `[TELEFONO]` / `[CONTRASEÑA]`

Instrucciones sugeridas:

1. Iniciar sesión como cliente.
2. Crear una solicitud de prueba.
3. En otro dispositivo, iniciar sesión como conductor.
4. Activar disponibilidad y aceptar la solicitud.
5. Regresar a la cuenta cliente y comprobar el estado.

No usar cuentas personales ni credenciales administrativas para la revisión.
